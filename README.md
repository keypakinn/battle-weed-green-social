# Battle Weed: Green Social (v2.6)

เกมยิงหาของลับออนไลน์ 2–7 คน ธีมสายเขียว ชุด 420 — สำหรับผู้มีอายุ 20 ปีขึ้นไป
กติกาฉบับเต็มอยู่ใน `spec.md` ในโฟลเดอร์เกม (`D:\Pakinn\Battle Weed Green Social\spec.md`)

## วิธีเล่น

1. คนแรกกด **สร้างห้อง** (เป็นหัวห้อง) ส่งลิงก์ให้เพื่อน หรือให้เพื่อนกดเข้าจากรายการห้องหน้าแรก (ค้นหาด้วยรหัสห้อง 4 หลักได้ · ห้องส่วนตัวใช้รหัสผ่าน 4 หลัก) 2–7 คน
2. หัวห้องตั้งค่า แล้วกด **เริ่มเกม**
   - **Classic** — คนละกระดาน 11×11 ทุกคน 5 ชิ้น เลือกยิงกระดานใครก็ได้
   - **Survival** — กระดานรวมเดียว (2 คน 13×13 · 3–4 คน 15×15 · 5 คน 16×16 · 6–7 คน 17×17) ใช้ชุดชิ้นเดียวกับ Classic (ครบชุด 27 ช่อง) คนเยอะชิ้นน้อยลง ของต่างคนทับกันได้ ยิงช่องที่มีของตัวเองได้และโดนด้วย
   - ตัวเลือก: **โดนแล้วได้ยิงเพิ่ม** · **เกาะส่วนตัว** (ไม่มี / สุ่ม / วาดเอง) · **ช่องกับดัก**
3. **วาง** อุปกรณ์รูปทรงตามภาพ (บ้องไผ่ 8 · เครื่องบด 4 · ไปป์ 8 · โรล 3 · ไฟแช็ก 4 ช่อง รวม 27 ช่อง ใช้เหมือนกันทุกโหมด) ใน 120 วินาที แตะช่องว่าง = วางชิ้นถัดไป (ช่องที่แตะ = มุมซ้ายบน) · แตะชิ้นบนกระดาน = เลือก แล้วแตะช่องอื่นเพื่อย้าย / หมุน / เอาออก · กดค้างที่ชิ้นแล้วลากได้ · "สุ่มวางให้"
4. **ยิง** — 2 คนผลัดตา นัดละ 15 วินาที (โดนแล้วยิงต่อได้จนพลาด) · 3 คนขึ้นไปทุกคนเลือกพร้อมกันทีละรอบ (โดนแล้วรอบหน้าได้ 2 นัด รอบนั้น 20 วินาที) · เลือกช่องไว้แล้วไม่ได้กดยิงจนหมดเวลา = ยิงช่องนั้นให้ นับเป็นการยิงเอง · Survival ยิงโดนช่องที่มีแค่ของตัวเองไม่ได้ยิงเพิ่ม
5. ชิ้นที่โดนครบทุกช่อง "ดับ" ดับครบทุกชิ้น = ตกรอบ · คนสุดท้ายที่เหลือชนะ
6. ยิงโดนเกาะคนอื่นได้นัดเพิ่ม · ทำลายเกาะครบได้นัดคู่ (2 ช่องติดกัน) · โดนกับดัก = ข้ามตาหน้า

## v2.6: ไม่กระพริบ · ผังล็อก · สีคนยิง
- ทุกการอัปเดตแก้เฉพาะจุดที่ต่าง ไม่แทนที่ DOM ทั้งหน้า (ยิง 1 ครั้งเคยสร้างใหม่ทั้งหน้า 3 รอบ)
- หน้าเล่นล็อกผัง จองที่ปุ่มยิง/ข้อความไว้เสมอ ของไม่ขยับระหว่างตา
- Classic: ถึงตายิงแล้วสลับไปแท็บคู่แข่งอัตโนมัติ
- ช่องที่ถูกยิงติดสีของคนยิง (state ส่ง pid คนยิงมาด้วย)
- ไฟล์ย่อยมีเลขรุ่นต่อท้าย กันเบราว์เซอร์ใช้โค้ดเก่าค้าง · หน้าแรกโชว์เลขรุ่น

## v2.5: ชิ้นเล็กลง · แบนเนอร์ตาเล่น · พอดีจอ
- ชุดชิ้นเดียว 27 ช่อง ทุกโหมด (ไม่มี id รุ่น `-s` แล้ว) กระดาน Classic 11, Survival 13/15/15/16/17/17
- ถึงตา: แบนเนอร์ใหญ่กลางจอ 3 วิ (`TURN_BANNER_MS`) แตะที่ไหนก็หายทันที การแตะยังทำงานปกติ

## เสียง แชท และเสียงสด (v2.4)

- **เสียง:** เอฟเฟกต์และดนตรีประกอบสังเคราะห์ด้วย Web Audio ในโค้ด (`public/sfx.js`) ไม่มีไฟล์เสียง · ปุ่ม 🔊 / 🎵 บนแถบด้านบน จำค่าไว้ในเครื่อง · เสียงเริ่มได้หลังแตะจอครั้งแรก · BGM แนวสนามรบเล่นช่วงวางชิ้นและช่วงยิง เร่งจังหวะเมื่อเหลือ 5 วินาทีของตาตัวเอง
- **นับถอยหลัง:** ตัวเลขใหญ่แสดงตอนเหลือ 5 วินาที (5→1) เฉพาะคนที่ต้องยิง
- **แชท 💬:** ในห้อง ไม่เกิน 100 ตัวอักษร ส่งได้ทุก 1 วินาที เก็บ 30 ข้อความล่าสุดในหน่วยความจำของห้อง (ห้องหาย = แชทหาย) แตะชื่อเพื่อซ่อนข้อความของคนนั้นเฉพาะในเครื่องเรา
- **เสียงสด 🎙:** WebRTC เชื่อมตรงระหว่างผู้เล่น เสียงไม่ผ่านเซิร์ฟเวอร์ (server ส่งต่อแค่ข้อความเชื่อมต่อ `rtc`) ไมค์ปิดเป็นค่าเริ่มต้น ใช้ STUN ฟรีของ Google ไม่มี TURN → บางเครือข่ายต่อกันไม่ติด · ต้องเปิดผ่าน HTTPS (Render ให้อยู่แล้ว)

## ข้อมูลชิ้นและภาพ (แก้ที่โฟลเดอร์เกม ไม่ใช่ที่นี่)

- ข้อมูลชิ้น: `cards.csv` ในโฟลเดอร์เกม คอลัมน์ `id, name, shape, image` — `shape` เขียนแถวคั่นด้วย `/` (`X` = มีช่อง, `.` = ว่าง)
- ภาพ: วางใน `art\` ของโฟลเดอร์เกม แล้วกรอกชื่อไฟล์ในคอลัมน์ `image`
- แล้วบอก Claude ให้อัปเดต — Claude สร้าง `cards/data.csv`, `cards/art/<id>.webp`, `cards/fit.json` ในโฟลเดอร์นี้ใหม่
- ไม่มีภาพ = ช่องของชิ้นเป็นสีพื้นพร้อมชื่อ เกมเล่นได้ปกติ
- ชิ้นรุ่นเล็กของ Survival (`bong-s`, `grinder-s`, `pipe-s`, `joint-s`, `lighter-s`) ใช้ภาพเดียวกับรุ่นเดิม โดยใส่คีย์ `art` ใน `cards/fit.json` (เช่น `"art": "bong"`)

## ติดตั้งเป็นแอปบนหน้าจอโฮม

หน้าแรกมีปุ่ม **📲 เพิ่มไปหน้าจอโฮม**
- **Android (Chrome):** กดแล้วขึ้นหน้าติดตั้งทันที · แอปล็อกแนวตั้ง
- **iPhone (Safari):** กดแล้วบอกวิธี (แชร์ → เพิ่มไปยังหน้าจอโฮม) — เว็บติดตั้งเองบน iPhone ไม่ได้
- **เปิดจาก LINE / Facebook:** กดแล้วบอกให้เปิดใน Safari / Chrome ก่อน พร้อมปุ่มคัดลอกลิงก์

## โครงสำหรับนักพัฒนา

| ไฟล์ | หน้าที่ |
|---|---|
| `server.js` | Express + Socket.IO, ห้อง, ส่ง `state` + `notice`, งานเบื้องหลังทุก 0.5 วินาที |
| `game.js` | `class Room` กติกาทั้งหมด + `CONFIG` (ตาราง config ของ spec) อ้างรหัสกติกา R-x-yy |
| `server/cards.js`, `server/parse-csv.js` | อ่านและตรวจ `cards/data.csv` + `cards/fit.json` |
| `public/` | หน้าเว็บ (`app.js` render ทั้งหน้าจาก state), `sfx.js` (เสียง + BGM), `voice.js` (เสียงสด WebRTC), PWA (`manifest.json`, `sw.js`, `icons/`) |
| `cards/` | `data.csv`, `fit.json` (ตำแหน่งภาพในช่อง), `art/*.webp` |
| `test/sim.js` | test ตาม test scenario ของ spec (T-01..T-70, 68 test) |

Socket: client ส่ง `create`, `join`, `resume`, `leave`, `action {type, reqId, ...}` (type = `update_settings`, `start_game`, `suggest_placement`, `submit_placement`, `fire`, `resign`, `rematch`, `back_to_lobby`, `chat`, `voice_join`, `voice_leave`) และ `rtc {to, kind, data}` (เสียงสด) ตอบผ่าน ack `{ ok, code?, error? }` · server ส่ง `state` (เฉพาะสิ่งที่ผู้เล่นคนนั้นเห็นได้), `notice` (แจ้งเตือนทุกคน/ส่วนตัว) `chat` / `chat_log` (แชท), `rtc` (ข้อความเชื่อมต่อเสียงสด) และ `replaced`
