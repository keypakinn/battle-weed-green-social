# Battle Weed: Green Social

เกมยิงช่องออนไลน์ 2 คน (Battleship คลาสสิก) ธีมสายเขียว ชุด 420 — สำหรับผู้มีอายุ 20 ปีขึ้นไป
กติกาฉบับเต็มอยู่ใน `spec.md` ในโฟลเดอร์เกม (`D:\Pakinn\Battle Weed Green Social\spec.md`)

## วิธีเล่น

1. คนแรกกด **สร้างห้อง** แล้วส่งรหัส 5 ตัวหรือลิงก์ให้เพื่อน เพื่อนเข้าห้อง ครบ 2 คนเกมเริ่มเอง
2. **วาง** อุปกรณ์ 5 ชิ้น (บ้อง 5 · เครื่องบด 4 · ไปป์ 3 · โรล 3 · ไฟแช็ก 2 ช่อง) ภายใน 90 วินาที
   แตะการ์ด → แตะช่องเริ่ม · ปุ่มหมุนสลับแนวนอน/แนวตั้ง · วางชิดกันได้ ห้ามซ้อน · มีปุ่ม "สุ่มวางให้"
3. **ยิง** ผลัดกันตาละนัด 30 วินาที แตะช่องบนกระดานคู่แข่ง: ควันลอย = พลาด · โดน! = มีของ · ยิงครบทุกช่องของชิ้นไหน = ชิ้นนั้น "ดับ"
4. ทำให้ของอีกฝ่ายดับครบก่อนชนะ · หมดเวลา ระบบยิงแทน · ถูกยิงแทน 3 ตาติด = แพ้ · หลุดเกิน 60 วินาที = แพ้
5. จบแล้วกด **เล่นอีก** ทั้งคู่ คนที่แพ้เกมก่อนได้เริ่มก่อน

## รันในเครื่อง

```
npm install
npm start            # http://localhost:3000
npm test             # ทดสอบกติกา (test/sim.js)
```

หน้า `/preview` แสดงการ์ดทุกใบ · `/healthz` ตอบ `ok`

## Deploy (GitHub → Render ฟรี)

- อัปโหลด**ทุกไฟล์ในโฟลเดอร์นี้** ขึ้น GitHub (ยกเว้น `node_modules`)
- Render: New → Web Service → เลือก repo · Build `npm install` · Start `npm start` · Instance type **Free**
- deploy ใหม่ / รีสตาร์ต = ห้องที่เล่นอยู่หายทั้งหมด ควรอัปตอนไม่มีคนเล่น
- แพ็กเกจฟรีจะหลับเมื่อไม่มีคนใช้สักพัก เปิดครั้งแรกอาจรอราว 1 นาที

## Environment variables

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `PORT` | พอร์ต (ค่าเริ่มต้น 3000, Render ตั้งให้เอง) |

## การ์ด (แก้ที่โฟลเดอร์เกม ไม่ใช่ที่นี่)

- ข้อมูลการ์ด: แก้ `cards.csv` ในโฟลเดอร์เกม (`D:\Pakinn\Battle Weed Green Social\cards.csv`)
- ภาพ: วางใน `art\` ของโฟลเดอร์เกม แล้วกรอกชื่อไฟล์ในคอลัมน์ `image`
- แล้วบอก Claude ให้อัปเดต — Claude จะสร้าง `cards/data.csv` และ `cards/art/<id>.webp` ในโฟลเดอร์นี้ใหม่ จากนั้นอัปทั้งโฟลเดอร์ขึ้น GitHub อีกครั้ง
- ยังไม่มีภาพ = ช่องภาพเป็นพื้นเขียวพร้อมชื่อการ์ด เกมเล่นได้ปกติ

## ติดตั้งเป็นแอปบนหน้าจอโฮม

- **iPhone (Safari):** เปิดเว็บ → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม" (ลิงก์เชิญเข้าห้องที่กดจากแชทจะเปิดใน Safari ไม่ใช่ในแอปที่ติดตั้ง)

## โครงสำหรับนักพัฒนา

| ไฟล์ | หน้าที่ |
|---|---|
| `server.js` | Express + Socket.IO, ห้อง, routes, งานเบื้องหลังทุก 0.5 วินาที |
| `game.js` | `class Room` กติกาทั้งหมด + `CONFIG` (ตาราง config ของ spec) อ้างรหัสกติกา R-x-yy |
| `server/cards.js`, `server/parse-csv.js` | อ่านและตรวจ `cards/data.csv` ตาม `shared/card-schema.js` |
| `public/` | หน้าเว็บ (`app.js` render ทั้งหน้าจาก state), `card.js`/`card.css` ตัวประกอบการ์ด, PWA (`manifest.json`, `sw.js`, `icons/`) |
| `cards/` | `template.json`, `frame.png`, `data.csv`, `art/` |
| `test/sim.js` | test ตาม test scenario ของ spec (T-01..T-33) |

Socket: client ส่ง `create`, `join`, `resume`, `leave`, `action {type, reqId, ...}` (type = `suggest_placement`, `submit_placement`, `fire`, `resign`, `rematch`, `back_to_lobby`) ทุกคำสั่งตอบผ่าน ack `{ ok, code?, error? }` · server ส่ง `state` (เฉพาะสิ่งที่ผู้เล่นคนนั้นเห็นได้) และ `replaced`
